# Comparison of equivalent soil mass and fixed depth methods for soil organic carbon stock calculations

This repo contains the R code and most data needed to calculate total soil organic carbon (SOC) stocks via fixed depth and equivalent soil mass methods from the Dynamic Soil Properties for Soil Health v.1.0 database, and generate analyses, tables, and figures from *Dynarski, K.A.\*; Kandanool, D.\*; Adeleke, E.; Veum, K.S; Carter, T.; Wills, S.A. Comparison of equivalent soil mass and fixed depth methods for soil organic carbon stock calculations. In revision at Geoderma (2026).* 

Equivalent soil mass calculations were performed using the SimpleESM R script by Fabien Ferchaud, which is available at: https://github.com/fabienferchaud/SimpleESM

**Repo contents:**

* Code to perform analyses, tables, and figures in manuscript: code/esm_manuscript_revision2.Rmd
* Report with tables and figures from manuscript: code/esm_manuscript_revision2.md
* Code to prepare data for SimpleESM script: code/esm_input_revision.R
