# Comparison of equivalent soil mass and fixed depth methods for soil organic carbon stock calculations in space-for-time experimental designs

This repo contains the R code and most data needed to calculate total soil organic carbon (SOC) stocks via fixed depth and equivalent soil mass methods from the Dynamic Soil Properties for Soil Health v.1.0 database, and generate analyses, tables, and figures from *Dynarski, K.A.\*; Kandanool, D.\*; Adeleke, E.; Veum, K.S; Carter, T.; Wills, S.A. Comparison of equivalent soil mass and fixed depth methods for soil organic carbon stock calculations in space-for-time experimental designs. In preparation (2025).* 

Equivalent soil mass calculations were performed using the SimpleESM R script by Fabien Ferchaud, which is available at: https://github.com/fabienferchaud/SimpleESM

**Repo contents:**

* Code to perform analyses, tables, and figures in manuscript: code/esm_ms.Rmd
* Report with tables and figures from manuscript: code/esm_ms.md
* Code to prepare data for SimpleESM script: All .R files beginning with "esm_input"
